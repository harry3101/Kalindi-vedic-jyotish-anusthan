# Divine Guidance Hub

Create a modern, professional, fully responsive Vedic astrology website similar in structure, design language, and content style to https://www.vinaybajrangi.com/. The website should feel premium, trustworthy, spiritual yet clean, with deep saffron, gold, deep maroon, cream, and white color palette. Use elegant serif + clean sans-serif typography. Include smooth animations, sticky header, and mobile-first design.

Brand & Positioning

Position the site as a trusted Vedic astrology consultation platform focused on accurate Navamsa-based (D-9) analysis, karmic insights, and practical solutions.

Name the astrologer something professional (or leave as placeholder “Astrologer Name”). Emphasize 25+ years experience, thousands of kundlis analyzed, media features, and ethical practice.

Completely exclude any Courses / Astro Courses / Webinar / Learning section. Do not add any course-related pages or menu items.

Each service should have description, benefits, and “Book Now” / “Get Report” CTA

Free Kundli / Birth Chart Generator

Beautiful form: Name, Gender, Date of Birth, Exact Time of Birth, Place of Birth (with city autocomplete if possible)

Show a success message and option to download/print the kundli
